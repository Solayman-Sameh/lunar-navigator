# User interaction contract
1 Global; 2 Approach/replay; 3 Local; 4 Surface. F focus. R reset. Space pause/resume.
Esc closes popup, else skips approach, else returns Surface -> Local -> Global. H or ? opens Help. Tab hides/restores overlays.
Left drag orbits/looks; scroll zooms (Surface changes height). Double-click a marker selects and focuses. Clicking marker selects. Skip button completes approach. All pointer camera actions are blocked over interactive UI.
Sites list selects and exposes all four actions. Layers toggles markers, stars and scientific direction aids. Settings changes graphics, speed and observer height. Timeline scrubs 30 days and steps +/- one hour. UTC is always labeled. All synthetic directions are labeled Illustrative Demo Provider; terrain and site status remain visible.
