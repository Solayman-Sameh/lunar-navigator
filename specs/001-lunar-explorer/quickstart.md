# Validation guide
1. Open Assets/Scenes/LunarNavigator_Main.unity, enter Play Mode. Expect lit, detailed Moon and floating controls.
2. Drag and scroll Global, select each marker or use Sites. Focus, approach, skip, replay and interrupt with mode keys.
3. Orbit/zoom locally, enter Surface, look around and change height. Return through every mode 20 times.
4. Click UI and confirm no world drag. Open Help, dismiss with Esc/outside click, toggle Tab twice.
5. Play, pause, change speed, scrub and step time. Inspect lighting changes and demo labels.
6. Switch all three graphics presets. Capture Global/Local/Surface, check materials and horizon.
7. Run Lunar Navigator/Verify in Editor and runtime verification through Editor tools. Review Console and Documentation/Verification outputs.
